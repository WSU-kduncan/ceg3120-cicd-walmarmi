## README

- The Goal of these projects are to be more familiar with the use of Docker, Github Actions, and Instance usages with running applications automatically.
- README-CI.md: This is where we are using Docker more in our own local environment and setting it up with our repository and images and containers. We also dabble into Github actions and the use of secrets that can be used for sensitive information like linking your Docker token directly.
- README-CD.md: This is more of Instance work and primarily focuses on being able to write a script that can automatically update the code when it's being pushed or committed by a developer. We use Docker and Github with an EC2 instance to mimic this simulation and focuses on tagging and webhooks.
